# Whitechapel Terminal Interface

A terminal-style interactive mystery game set in 1888 London.

## Play Online

🎮 **[Play the game here](https://ryangu514.github.io/project3-IXP/)**

## About

An interactive terminal interface where you investigate audio logs from a mysterious case in Whitechapel. Listen to three different audio logs and piece together the evidence to solve the mystery.

### Features
- 🖥️ Retro terminal aesthetic with CRT effects
- ⌨️ Typewriter text animation
- 📼 Three interactive audio log files
- 🔍 Mystery solving gameplay
- 📱 Responsive design for desktop and mobile

### How to Play
1. Click on any audio log file to play it
2. Listen to all three logs
3. The ending will reveal once all logs are complete
4. Use ESC key to return to the file list

## Technology
- Pure HTML, CSS, and JavaScript
- No external dependencies
- Single-file application
